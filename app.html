🚀 게시 설정 (최초 1회)

게시하기는 이 브라우저가 GitHub 저장소의 data/tournament.json 을 직접 커밋합니다. 그러려면 저장소에 쓸 수 있는 GitHub 토큰이 필요합니다.

  1. github.com/settings/personal-access-tokens/new 를 새 탭에서 열기 (GitHub 로그인 필요). 이름은 아무거나, 만료는 대회 뒤로.
  2. Repository access: Only select repositories → koozinsong/tennisweet
  3. Permissions → Repository permissions → Contents: Read and write (다른 권한 불필요)
  4. 생성된 토큰(github_pat_…)을 아래에 붙여넣기

토큰은 관리자 비밀번호로 암호화되어 저장되고 게시본에도 암호화된 채 실립니다. 그래서 한 번만 넣으면 다른 기기에서도 관리자 비밀번호만으로 게시할 수 있습니다. 만료되거나 틀리면 다시 묻고, 지우려면 게시하기 버튼을 길게 누르거나(우클릭) 초기화하세요.

선수 명단

참가 선수 명단입니다. 합류 시각은 그 시각부터 경기에 배정됨을 뜻합니다.

기본 명단은 저장소의 data/tournament.json 게시본에서 불러오며, 편집 모드에서 추가·수정한 내용은 이 브라우저에 저장됩니다. 셀을 클릭하면 바로 수정할 수 있습니다. 합류 시각을 비우면 대회 시작부터 참가합니다. NTRP 는 관리자 로그인 시에만 표시되며 파일에도 암호화되어 저장됩니다. 같은팀 묶음에 같은 표시(예: A)를 넣은 선수들은 항상 한 팀에 배정됩니다 (관리자에게만 표시).
